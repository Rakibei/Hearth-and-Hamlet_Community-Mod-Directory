# Contributing

Thank you for contributing to the Community Mod Directory.

The goal of this repository is to maintain a simple, community-managed list of available mods.

## Adding a Mod

To add your mod:

1. Fork this repository.
2. Edit `README.md`.
3. Add your mod to the mod table.
4. Commit your changes.
5. Open a Pull Request.

Please submit **one mod per row** using the following format:

```md
| Mod Name | Author | Short description of the mod. | [GitHub](https://github.com/yourname/your-mod) |
```

## Submission Requirements

Submitted mods should:

* Be publicly available.
* Have a working repository or download link.
* Clearly identify the mod author.
* Include a short and accurate description.
* Provide enough documentation for users to understand what the mod does.
* Follow the rules and guidelines of the game and its modding community.

Mods containing malware, intentionally harmful code, stolen work, misleading links, or other malicious content will not be accepted.

## Updating a Mod

If your mod changes name, description, repository, or download location, open a Pull Request updating the existing entry.

Please edit the existing row rather than adding a second entry.

## Removing a Mod

If you are the author or maintainer of a listed mod and would like it removed, you may:

* Open a Pull Request removing the entry.
* Open an Issue requesting its removal.

## Fixing Existing Entries

Contributions are also welcome for:

* Broken links
* Outdated information
* Incorrect descriptions
* Duplicate entries
* Formatting issues

## Pull Request Guidelines

When submitting a Pull Request:

* Keep changes limited to the mod or issue you are addressing.
* Avoid unrelated formatting changes.
* Do not modify other mod entries unless necessary.
* Use a clear Pull Request title.

For a new mod, a title such as the following is recommended:

```text
Add Toggle Harvest
```

For an update:

```text
Update Toggle Harvest link
```

Maintainers may request changes before accepting a submission.
