# Community Mod Directory

A community-maintained directory of mods.

This repository does **not** host mods directly. Instead, it provides a central place where mod authors can share links to their projects and where players can discover mods created by the community.

## Disclaimer

Mods listed here are created and maintained by independent community members.

Being listed in this repository does **not** mean that a mod has been reviewed, verified, endorsed, or guaranteed to be safe.

Always review a mod's documentation and source code before installing it when possible.
