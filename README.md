# Community Mod Directory

A community-maintained directory of mods.

This repository does **not** host mods directly. Instead, it provides a central place where mod authors can share links to their projects and where players can discover mods created by the community.

## Essential Modding Tools

These are recommended for anyone looking to install, create, or manage mods.

### Hearth & Hamlet Godot Mod Loader

[Hearth and Hamlet GML Github](https://github.com/Rakibei/Hearth-and-Hamlet_GML)

The mod loader used to add mod support to Hearth & Hamlet.

If you are planning to use or develop mods for the game, this should be your starting point.

### Mod Menu

[Mod Menu Github](https://github.com/Rakibei/Rakibei-ModMenu)

An in-game mod menu for managing installed mods and their configuration options.

It provides a common interface that mods can use for configurable settings instead of requiring each mod to implement its own configuration UI.
